# Modul: Lokalisierung

> Schicht 0 (`core/i18n`) + Schicht 1 (`content/locales`) · Status 🟢 M7 abgeschlossen

## Zweck

Deutsch und Englisch, vollständig. Menüs, HUD, Hinweise, Gegenstandsnamen,
Wetter, Anomalien, Aufträge, Questlinie, Meldungen.

## Deutsch ist die Quellsprache

Der wichtigste Entwurfsentscheid: **Der Katalog wird mit dem deutschen Satz
selbst geschlüsselt**, nicht mit einer Kennung.

```ts
t('Ausrüstung wählen')          // → 'Choose loadout' oder unverändert Deutsch
tf('Stufe {level}', { level })  // Platzhalter, keine Verkettung
```

Das bringt drei Dinge:

1. **Es gibt keinen deutschen Katalog zu pflegen.** Ein Schlüssel ohne Eintrag
   kann einem deutschen Spieler kein `ui.base.title` zeigen, weil der Schlüssel
   *der deutsche Text ist*. Der schlimmste denkbare Fehler ist ein einzelnes
   deutsches Wort für einen englischen Spieler — ein Schönheitsfehler, kein
   kaputter Bildschirm.
2. **Aufrufstellen bleiben lesbar.** `t('Ausrüstung wählen')` sagt, was
   gerendert wird. `t('ui.loadout.confirm')` muss man nachschlagen.
3. **Eine Sprache dazu ist eine Datei.** Kein Umbenennen, keine
   Schlüsseldisziplin, keine Abstimmung zwischen dem, der den Bildschirm
   schreibt, und dem, der übersetzt.

Der Preis ist der klassische: Zwei deutsche Wörter, die verschiedenes Englisch
brauchen, kollidieren. `context` löst das wie gettexts `msgctxt` — Schlüssel ist
`context + U+0004 + source`. Das Trennzeichen ist genau deshalb ein
Steuerzeichen: Bei simpler Verkettung wären `("toas", "tX")` und
`("toast", "X")` derselbe Schlüssel.

## Platzhalter statt Verkettung

```ts
tf('Noch {minutes} Minuten', { minutes: 3 })
```

Nicht `'Noch ' + n + ' Minuten'`. Wortstellung unterscheidet sich zwischen
Sprachen, und einen zusammengesetzten Satz kann eine Übersetzerin nicht
umstellen. Ein Test prüft, dass jede Übersetzung **dieselben** Platzhalter
enthält wie ihre Quelle — ein fehlendes `{count}` ergibt einen Satz mit einem
Loch, und das Loch ist unsichtbar, bis jemand in dieser Sprache spielt.

Plurale sind eigene Quellzeichenketten (`{count} Kammer` /
`{count} Kammern`), kein im Code angeklebtes Suffix.

## Wo übersetzt wird

| Ort | Warum dort |
|-----|------------|
| `toHudItems()` im View-Model | Ein Ort für **alle** Gegenstandsnamen statt zwanzig Renderstellen |
| Aufrufstellen in `ui/**` | Bildschirmtexte, direkt sichtbar |
| `app/game.ts` | Meldungen und Banner |
| `el()` in `dom.ts` | `toLocaleString` folgt der Sprache: 8.000 vs 8,000 |

**Nicht** übersetzt wird in `game/**`. Die Simulation hat keine Sprache und darf
keine haben (ADR-002). Das war beim Interaktionsziel zu spüren: Es lieferte
einen fertigen Satz (`"Feldverband ×3"`). Jetzt liefert es Name und Menge
getrennt, und das View-Model setzt zusammen — sonst ließe sich die Sprache nur
zwischen zwei Raids wechseln.

## Sprachwahl

Beim Start: gespeicherte Wahl, sonst `navigator.language`. Gespeichert **außerhalb
des Profils**, denn eine Sprache gehört zur Person, nicht zur Spielfigur — ein
Profil-Reset darf die Menüs nicht auf Deutsch zurückwerfen.

Umschalten im Pausenmenü, als **Reihe** aus beiden Sprachen, jede in ihrer
eigenen Sprache beschriftet. Ein Umschalter mit der Aufschrift „Sprache:
Deutsch" hilft niemandem, der kein Deutsch liest. Der Wechsel wirkt sofort, auch
mitten im Raid: Der Zustandsautomat baut den aktuellen Bildschirm neu.

## Die Tests sind das Eigentliche

Ein Katalog verrottet lautlos. Das ist nicht theoretisch — beim ersten Lauf
fanden die Tests **40 nicht übersetzte Aufrufstellen**, und Browser-Screenshots
danach noch einmal Biomnamen, Bedrohungsstufen und zwei Zählformen.

| Test | Findet |
|------|--------|
| Aufrufstellen-Scan | Jedes literale `t('…')` in `ui/` und `app/` ohne Eintrag |
| Inhaltsabdeckung | Namen und Beschreibungen aus `content/`, die auf einem Bildschirm landen — was der Scan nicht sehen kann, weil `t(def.name)` erst zur Laufzeit bekannt ist |
| Platzhalter-Gleichheit | Übersetzungen, die ein `{count}` verloren haben |
| Identische Einträge | Copy-Paste; legitime Fälle (Produktnamen, „Sprint") stehen als Liste im Test, damit ein neuer eine bewusste Entscheidung ist |
| Browser-Smoke, englischer Durchlauf | Ein fehlendes Label auf dem Weg Menü → Basis → Ausrüstung → Briefing → Raid |

Der Inhaltstest prüft bewusst **nicht** alles: Item-`description`-Felder werden
derzeit nirgends gerendert, und eine Übersetzung für einen Text zu verlangen,
den niemand sieht, ist der Weg, auf dem ein Katalog sich mit Arbeit füllt, die
nichts schützt.

## Entscheidungen

| Entscheidung | Begründung |
|--------------|------------|
| Deutsch als Quellsprache, Schlüssel = Quelltext | Kein deutscher Katalog, kein Roh-Schlüssel auf dem Bildschirm, lesbare Aufrufstellen |
| U+0004 als Kontext-Trennzeichen | Verkettung allein ist mehrdeutig |
| Platzhalter statt Verkettung | Wortstellung ist sprachabhängig |
| Plurale als eigene Quellzeichenketten | Ein angeklebtes „n" ist deutsche Grammatik im Code |
| Übersetzung im View-Model, nicht in der Simulation | Sonst wechselt die Sprache erst nach dem Raid (ADR-002) |
| Sprache außerhalb des Profils | Sie gehört zur Person, nicht zur Spielfigur |
| Umschalter zeigt beide Sprachen gleichzeitig | Wer die aktuelle nicht liest, liest auch den Umschalter nicht |
| Abdeckung als Test | Ein Katalog verrottet lautlos; hier fällt er auf |
